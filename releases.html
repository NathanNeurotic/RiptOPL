Releases and packages

For a first installation, choose the full RiptOPL kit. Choose the RetroAchievements kit if you use xeRAbora. The RiptOPLite channel supplies smaller loaders for existing installations that use one game device. All three channels use the built-in PSBBN theme, with List, Grid, Coverflow and PSBBN Flow views.

Editions and channels

EditionChannelDownload
RiptOPLrollingStandard full kit, built with LLVM/Clang and marked Latest. Choose RIPTOPL-<version>.zip.
RetroAchievementsrolling-raFull GCC kit with the pinned NULD runtime and a xeRAbora shortcut. Choose RIPTOPL-RetroAchievements-<version>.zip.
RiptOPLite and RiptOPLite RArolling-liteGCC loaders for individual game devices. The standard loaders are ELFs, and RA loaders come in ZIPs with the matching runtime.

What each channel carries

Both full kits include the matching app under APPS/, artwork, a PSU app save, POPS/ drivers, EMBER/, the bundled Neutrino runtime, licenses and credits. Both channels publish the packed ELF, source snapshot, language pack, build manifest and SHA-256 checksums. Sony BIOS and emulator files must be supplied separately where required.

  • RiptOPL: RIPTOPL-VARIANTS-<version>.zip contains pademu0, ds5, extras and extras_ds5. RIPTOPL-DEBUG-<version>.zip contains diagnostic configurations. RIPTOPL-BUGREPORT-<version>.zip contains the unpacked diagnostic loader and reporting instructions.
  • RetroAchievements: RIPTOPL-RA-VARIANTS-<version>.zip contains pademu0 and unpacked loader builds. Use the runtime packaged with the RA release.

For the supported options and exact toolchains, see Build configurations and the release contract.

RiptOPLite: one loader per game device

rolling-lite is for consoles that play from one device only. Each standard build includes the game drivers for its chosen device; the memory card (MMCE) and network modules stay in every build, and the RetroAchievements builds also keep everything RetroAchievements uses on any device.

HTTP and PC Card CF have no lite build. A standard Lite ELF can replace RIPTOPL.ELF in an existing RiptOPL installation. Keep the companion folders for any cores you use. RetroAchievements needs files outside the loader (NULD's Neutrino RA runtime, formerly ORBIT), so each RA lite download is a ZIP with the ELF, neutrino/, the xeRAbora shortcut, licences, manifest and a README saying where each goes. A lite loader shares the full loader's settings file and leaves the device settings it has no drivers for unchanged; it cannot read settings from such a device, so keep them on its own device, a memory card or a USB stick. The channel also carries BUILD-MANIFEST.json, SHA256SUMS.txt and LICENSE-USMB2.txt. See RIPTOPLITE.md.

Moving from an earlier edition

Older Korium, IncebtIon and RiptOPLLVM installations use earlier channel names. Switch once by downloading and installing the full current kit manually. Back up your settings and saves first. Copy the companion folders with the new kit so the installed loader, Neutrino and POPStarter drivers agree. The standard RiptOPL kit now uses LLVM/Clang.

Installing and updating

Use Install & First Boot to copy the app and companion files. Standard RiptOPL and RetroAchievements can check their own channels from the main menu after that first manual migration. The updater replaces the ELF. Read the release notes to see when to update the companion folders separately.

Identify a tested build

Report the source commit, edition, configuration and compiler from BUILD-MANIFEST.json, plus your PS2 model, storage device, launch core and exact result. Verify the download with its channel's SHA256SUMS.txt.

Stable download links

Install ZIP names include the version. For a loader-only replacement, use RIPTOPL.ELF or RIPTOPL-RA.ELF. Match the loader to the kit already installed.

Bundled Neutrino core

The standard kit uses the Neutrino development release selected at packaging time, with RiptOPL's UDPFS configuration and i.LINK drivers. The RetroAchievements kit uses NULD v1.2.14 (formerly ORBIT). Use each kit's own neutrino/ folder. See Neutrino and RetroAchievements.

Download a PR or Actions test build

Open the supplied Actions run and verify the commit. Under Artifacts, release-riptopl-attempt<run> and release-ra-attempt<run> contain their full kits. Variant and Lite artifacts carry individual loader builds. Test artifacts expire. See Test builds for artifact names and report details.

What changed

Each channel's release notes list the ten newest changes in the build and link the full history, so they are always current for that build. Read them on the releases list, or see the rebuild/main history for everything merged since the last publish.

Older builds

Each channel holds only its newest build. The MEGA rolling archive keeps historical builds of the legacy C edition; automatic archiving of the C++ editions is not set up, so keep a copy of a build you may want to return to.

Building it yourself

With ps2build installed, run from the repository root:

python tools/assets.py fetch
python tools/assets.py lang
python tools/build_edition.py riptopl
python tools/build_edition.py riptopl --configuration extras

Build riptopl for the standard LLVM loader, ra for GCC RetroAchievements, or lite and lite_ra with --device <device> for RiptOPLite. See ROLLING_RELEASE.md and Build configurations.

External Tools & Services

PS2-Servers by Ripto — all-in-one PC server launcher for SMB, NFS, UDPFS, UDPBD and HTTP.
udpfs-server by YouKnow-sys — the same idea from a phone: an Android app that shares folders and disk images to the PS2 over UDPFS, found by broadcast so there is no server address to type in on the console. Built on udpfsd by pcm720; MIT licensed.
OrbitPS2 Manager by Luden — cross-platform PC library manager for importing discs, artwork/screenshots, ZSO compression, per-game settings and VMC management.
RIPPS2 by Akilluminati47 — a PS2 front end and loader affiliated with RiptOPL, with its own interface, game libraries, Memory Files browser and save tools. Built on the RiptOPL legacy C tree; see its releases for current PS2 builds.
OPL PS1 AIO Converter GUI by shaan — Windows all-in-one PS1/POPStarter preparation tool for BIN/CUE → VCD conversion and installation to USB, MX4SIO, MMCE, iLink, exFAT HDD, SMB and APA internal HDD.
xeRAbora by hacan359 — the PC client for RetroAchievements on real PS2 hardware. Client: v2.2.0; v1.0.1 (alpha.17 or later) also works. RiptOPL's RA build reads both clients' watch lists. After updating both the loader and client, run RA: check game support again for every game you play. xeRAbora runs rcheevos, talks to the RetroAchievements servers, unlocks achievements and builds the per-game watch list. Shipped as a shortcut inside RIPTOPL-RetroAchievements-<version>.zip; MIT licensed. RiptOPL’s RA stabilization on real hardware was driven by oMrRexD, whose PRs #702–#705 fixed the ee_core stack squeeze, MMCE DEV9 path, cold-launch networking and settings placement.
OPL HTTP PC server by Docmine17 — the PC side of RiptOPL’s HTTP protocol: a small static HTTP server with byte-range support that serves your games.csv catalog and streams the ISOs. RiptOPL works with it unmodified — no new API, no catalog conversion, no changed layout — with host conformance checks against the upstream server; PS2 hardware validation is still pending.
PS2RD CHT Manager by TheRealNextria — PC manager for the PS2RD .cht cheat files RiptOPL reads from your device's CHT folder.
Ember by Gageformer — a PS1 emulator running natively on the PS2, used as RiptOPL's second PS1 core alongside POPSTARTER. Ships as an EMBER/ folder inside the release package, bundled unmodified under the Ember Licence 1.0 (EMBER/LICENSE.txt); releases.
BDM-UDPFS Assault by Okeanos — UDPFS Assault (release 1.0.1 of 2026-11-08), the POPSTARTER network VCD driver RiptOPL ships as POPS/usbd.irx.udpfs: it reads every VCD file, plays .cue + .bin games without conversion, writes VMC saves on the PC and can share one save folder between the discs of a game (PATHMAP.INI). Based on israpps' BDM Assault.
POPStarter by krHACKen — a PS1 launcher built around Sony's native POPS emulator for the PS2, used as RiptOPL's primary PS1 core alongside Ember. POPStarter provides the compatibility and launch layer for running PS1 VCDs from USB, MX4SIO, MMCE, iLink, internal HDD, and SMB; RiptOPL's iLink handoff is wired but still awaiting a passing hardware retest. The official POPStarter r13 package contains no Sony emulator binaries, libraries, or BIOS files; those components must be supplied separately by the user. Official download, documentation, compatibility information, and releases are maintained on PSX-Place.
NULD (formerly ORBIT) Neutrino RA runtime by Daniel (danielnuld) — the existing RA-capable Neutrino runtime, bundled only in the RetroAchievements kit. Based on Neutrino by Maximus32 and xeRAbora protocol work by hacan359; AFL-3.0. Exact release, archive digest and source commit ship in neutrino/ORBIT-RA.json. Standard kits retain ordinary upstream Neutrino.
Neutrino by rickgaiser — a small, fast, modular PS2 device emulator, and RiptOPL's second PS2 loader core alongside OPL's own. Ships as a ready-to-use neutrino/ folder inside each installable ZIP (drag-and-drop to mc?:/neutrino/), under the AFL-3.0 licence; releases.
PSUManager by techwritescode — the CC0 PS2 save-container implementation used by RiptOPL release tooling to independently validate APP_RIPTOPL.psu and APP_RIPTOPL-RA.psu. The exact upstream core and license used by CI are preserved in third_party/PSUManager/.

Source and licenses

Each channel includes a source snapshot, credits, licensing and the exact build manifest. Companion binaries retain their own licenses. Every loader embeds usmb2 by Ronnie Sahlberg, used under the MIT licence, so every kit and bundle zip carries its licence, and each channel publishes the same file beside the standalone loader.
