Releases and packages

Three editions, one SDK: ps2build. GCC is the release compiler; GCC and LLVM are both checked in CI. Each edition has its own release channel, rebuilt from rebuild/main and verified before it is published.

Editions and channels

EditionChannelContents

RetroAchievementsrolling-raKorium theme with the RetroAchievements runtime and the xeRAbora client shortcut, plus the same kit built with the IncebtIon theme.

Development builds

Every channel is a development build. Publication checks the source commit, clean state, SDK consistency, file inventory and checksums, but a passing build does not mean it has been tested on your console, storage and settings. Check the release notes for the exact commit. Builds that are not published yet are in the Rolling Release runs as workflow artifacts.

What each channel carries

AssetWhat it is

RIPTOPL-src.zipGit's source archive of the exact built commit.
BUILD-MANIFEST.json, SHA256SUMS.txtBuild identity and asset checksums.

Every channel carries extra builds, built with its own theme, each as one folder per configuration with its own RIPTOPL.ELF and manifest, built from the same commit and SDK as the kit:

  • Korium and IncebtIon: RIPTOPL-VARIANTS.zip with pademu0 (pad emulation compiled out), ds5 (USB DualSense), extras (in-game screenshots and right-to-left languages) and extras_ds5; and RIPTOPL-DEBUG.zip with every debug and diagnostic configuration (dtl, diag, debug, debug_uart, ingame_debug, iopcore_debug, eesio_debug, ingame_debug_uart, iopcore_debug_uart, ingamediag).
  • RetroAchievements: RIPTOPL-RA-VARIANTS.zip with pademu0, and the IncebtIon-theme kit as RIPTOPL-RetroAchievements-IncebtIon.zip, RIPTOPL-RA-IncebtIon.ELF, APP_RIPTOPL-RA-IncebtIon.psu and RIPTOPL-RA-VARIANTS-IncebtIon.zip. Inside that kit the app is still APP_RIPTOPL-RA.

Standard kits never include RetroAchievements resources. No BIOS or Sony emulator file is distributed.

Installing

Use the edition's full install ZIP, extract it to the device root, and launch its app from APPS/. The accompanying PSU contains only the app and its direct metadata files for memory-card installation. Keep the bundled POPS, EMBER and neutrino folders beside APPS when using those cores; supply your own required BIOS/emulator components. See Installation and PS1 games.

Identify a tested build

Report the edition, source commit, SDK component versions and compiler from BUILD-MANIFEST.json, plus your hardware, storage backend and relevant settings. Verify downloads against SHA256SUMS.txt. The in-loader version names the edition, and any nonstandard configuration. The older ps2dev/official pinned and rolling SDK flavours belong to the legacy Open-PS2-Loader edition's release history; they are not built here.

Stable download links

Each channel's asset names never change, so these links always fetch the newest published build of that edition:

For a script, fetch SHA256SUMS.txt from the same channel and check the download against it, for example curl -LO https://github.com/NathanNeurotic/RiptOPL/releases/download/rolling-korium/RIPTOPL-Korium.zip followed by sha256sum -c --ignore-missing SHA256SUMS.txt.

Bundled Neutrino core

The Korium and IncebtIon kits carry the newest build of rickgaiser/neutrino's latest development release at the time the kit was built (v1.8.0-61-g7be8de2 on 2026-10-28; each channel's release notes name the included build), unmodified apart from RiptOPL's UDPFS config and i.LINK pair (see Neutrino Core). It is newer than Neutrino v1.8.0, which is what text cheats under Neutrino need (see Cheats). The RetroAchievements kits carry ORBIT's RA runtime instead, which is built on Neutrino v1.8.0 (see RetroAchievements). An ELF-only update never changes the neutrino/ folder; copy it from the kit when the release notes say it changed.

Download a PR or Actions test build

A test build belongs to one GitHub Actions run and commit, separate from the release channels. Open the run you were given, check its commit, sign in to GitHub and download the requested ZIP under Artifacts: release-<edition> is a complete install kit, variant-<edition>-<configuration> is one configuration's ELF and manifest. Artifacts expire; an expired one needs a new run. See Test builds for every artifact name and what a useful report contains.

Older builds

Each channel holds only its newest build. The MEGA rolling archive keeps historical builds of the legacy C edition; automatic archiving of the C++ editions is not set up, so keep a copy of a build you may want to return to.

Building it yourself

With ps2build installed, run from the repository root:

python tools/assets.py fetch
python tools/assets.py lang
python tools/build_edition.py korium
python tools/build_edition.py korium --configuration extras

The editions are korium, ra, incebtion and ra_incebtion. See ROLLING_RELEASE.md and Build configurations.

External Tools & Services

PS2-Servers by Ripto — all-in-one PC server launcher for SMB, UDPFS, UDPBD and HTTP.
udpfs-server by YouKnow-sys — the same idea from a phone: an Android app that shares folders and disk images to the PS2 over UDPFS, found by broadcast so there is no server address to type in on the console. Built on udpfsd by pcm720; MIT licensed.
OrbitPS2 Manager by Luden — cross-platform PC library manager for importing discs, artwork/screenshots, ZSO compression, per-game settings and VMC management.
LUNA by darkladark — Lightweight Unified Neutrino Access, a visual PS2 loader built on NHDDL and Neutrino, and our #1 recommended alternative if RiptOPL is more loader than you need. darkladark also contributes to RiptOPL: the PSBBN Flow theme adapts LUNA's Collection display (#733), keeping the normal R3 favorite action.
RIPPS2 by Akilluminati47 — our daughter project: a PS2-inspired front end with a web-theme beta at akilluminati47.github.io/RIPPS2. It now offers a downloadable PS2 ELF; consult its own releases and compatibility notes for current builds.
OPL PS1 AIO Converter GUI by shaan — Windows all-in-one PS1/POPStarter preparation tool for BIN/CUE → VCD conversion and installation to USB, MX4SIO, MMCE, iLink, exFAT HDD, SMB and APA internal HDD.
xeRAbora by hacan359 — the PC client for RetroAchievements on real PS2 hardware. Required client: v1.0.1 (alpha.17 or later). RiptOPL's RA build is paired with and requires xeRAbora v1.0.1 (alpha.17 or later). xeRAbora runs rcheevos, talks to the RetroAchievements servers, unlocks achievements and builds the per-game watch list. Shipped as a shortcut inside RIPTOPL-RetroAchievements.zip; MIT licensed. RiptOPL’s RA stabilization on real hardware was driven by oMrRexD, whose PRs #702–#705 fixed the ee_core stack squeeze, MMCE DEV9 path, cold-launch networking and settings placement.
OPL HTTP PC server by Docmine17 — the PC side of RiptOPL’s HTTP protocol: a small static HTTP server with byte-range support that serves your games.csv catalog and streams the ISOs. RiptOPL works with it unmodified — no new API, no catalog conversion, no changed layout — with host conformance checks against the upstream server; PS2 hardware validation is still pending.
PS2RD CHT Manager by TheRealNextria — PC manager for the PS2RD .cht cheat files RiptOPL reads from your device's CHT folder.
Ember by Gageformer — a PS1 emulator running natively on the PS2, used as RiptOPL's second PS1 core alongside POPSTARTER. Ships as an EMBER/ folder inside the release package, bundled unmodified under the Ember Public Beta Testing Licence (EMBER/LICENSE-BETA.txt); releases.
BDM-UDPFS Assault by Okeanos — UDPFS Assault (TEST pre-release of 2026-10-28), the POPSTARTER network VCD driver RiptOPL ships as POPS/usbd.irx.udpfs: it reads every VCD file, plays .cue + .bin games without conversion and writes VMC saves on the PC. Based on israpps' BDM Assault.
POPStarter by krHACKen — a PS1 launcher built around Sony's native POPS emulator for the PS2, used as RiptOPL's primary PS1 core alongside Ember. POPStarter provides the compatibility and launch layer for running PS1 VCDs from USB, MX4SIO, MMCE, iLink, internal HDD, and SMB; RiptOPL's iLink handoff is wired but still awaiting a passing hardware retest. The official POPStarter r13 package contains no Sony emulator binaries, libraries, or BIOS files; those components must be supplied separately by the user. Official download, documentation, compatibility information, and releases are maintained on PSX-Place.
ORBIT Neutrino RA runtime by Daniel (danielnuld) — the existing RA-capable Neutrino runtime, bundled only in the RetroAchievements kit. Based on Neutrino by Maximus32 and xeRAbora protocol work by hacan359; AFL-3.0. Exact release, archive digest and source commit ship in neutrino/ORBIT-RA.json. Standard kits retain ordinary upstream Neutrino.
Neutrino by rickgaiser — a small, fast, modular PS2 device emulator, and RiptOPL's second PS2 loader core alongside OPL's own. Ships as a ready-to-use neutrino/ folder inside each installable ZIP (drag-and-drop to mc?:/neutrino/), under the AFL-3.0 licence; releases.
PSUManager by techwritescode — the CC0 PS2 save-container implementation used by RiptOPL release tooling to independently validate APP_RIPTOPL.psu and APP_RIPTOPL-RA.psu. The exact upstream core and license used by CI are preserved in third_party/PSUManager/.
