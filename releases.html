ps2build C++ migration

This repository is the C++/ps2build transition of RiptOPL. These guides include the production project's full documentation; feature and hardware parity are still being validated. The release targets are Korium, RetroAchievements and IncebtIon, all on ps2build. Check the migration ledger before treating an imported production feature as verified here.

Releases and packages

Three editions, one SDK: ps2build. GCC is the release compiler; GCC and LLVM are both checked in CI.

Availability and validation

A channel becomes downloadable after its release build, package verification and deliberate publication succeed. The migration does not inherit the production repository's hardware acceptance. Preview artifacts are available in Rolling Release runs.

Installing

Use the edition's full install ZIP, extract it to the device root, and launch its app from APPS/. The accompanying PSU contains only the app and its direct metadata files for memory-card installation. Keep the bundled POPS, EMBER and neutrino folders beside APPS when using those cores; supply your own required BIOS/emulator components. See Installation and PS1 games.

Identify a tested build

Report the edition, source commit, SDK component versions and compiler from BUILD-MANIFEST.json, plus your hardware, storage backend and relevant settings. Verify downloads against SHA256SUMS.txt. The in-loader version also names the edition. Older ps2dev/official pinned and rolling SDK choices belong to the production repository's release history.

Source and licenses

Each channel includes a source snapshot, credits, licensing and the exact build manifest. Companion binaries retain their own licenses. Standard editions do not include the RA agent/client resources.
