What is here
- lib/*.c: the SMB2_CORE_SOURCES list from upstream lib/CMakeLists.txt.
  Local deviations from upstream:
  - socket.c: smb2_get_credit_charge() counts only the head request of a
    compound, matching the send path and [MS-SMB2] 3.2.4.1.1; upstream sums
    every chained request, which stalls a compound when the server grants a
    small credit window.
  - sync.c: wait_for_reply() enforces the configured deadline even while a
    socket is connected and a reply PDU has been removed from waitqueue for
    partial reception. On expiry it closes the session, since the remainder
    of that response cannot be safely parsed as a new SMB frame.
- lib/*.h, include/: upstream headers, unmodified.
- lib/config.h: the config.h that upstream's own CMake generates for the PS2 IOP
  target (cmake -DCMAKE_TOOLCHAIN_FILE=$PS2DEV/share/ps2dev_iop.cmake -DBUILD_IRX=1),
  committed so ps2build does not need CMake. One local addition, at its end: the
  `_U_` (unused) define, which upstream's CMake passes as a compiler flag instead
  and which aes128ccm.c, init.c, ntlmssp.c and sha384-512.c need.

What is omitted
- examples/, tests/, utils/, the other platform ports, and upstream's lib/ps2/
  smb2man front end. RiptOPL's front end is ../smb2man.c, which speaks the
  ps2smb.h devctl interface OPL's network menu already uses.
