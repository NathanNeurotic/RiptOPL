Source/header/import/export files and README are copied from that revision.
Makefile uses the SDK sample-module rules; RiptOPL builds it from ps2.yaml (iLinkman_fork).

RiptOPL recovery changes, also applied to POPStarter's embedded manager:
- iLink_TxRx.c: release UBUFTxSema on generation mismatch before packet commit.
- iLink_TxRx.c: cancel split-response alarm after every wait, including early IRQ
  errors, so a pending old alarm cannot poison a later transaction.
- iLink_intr.c: consume unhandled receive FIFO quadlets even with TTY disabled.

test_ilink_manager_recovery.py compiles the real functions with fault injection
and checks both copies with TTY on/off. The original source fails those cases.
These source/host findings do not establish the reporter's hardware cause.
October 22 follow-up:
- Latch request IRQ errors, wake on split timeout/bus reset, keep response-TX
  events separate, and retire outbound DMA before returning an error.
- Serialize public client requests while preserving receive-thread response TX.
- Match response node/label/type/generation/length, retire caller pointers,
  and wait for copied block-read data before returning.
- Check whole read/write packet spans, drain refusals and preserve partial words.
- Correct EUI64 import 25, CROM deletion/counts, relative leaf offsets and
  allocation-failure size publication. test_ilink_manager_irq.py and
  test_ilink_manager_safety.py exercise the real functions from both copies.
SBP-2 resident request storage and bounded completion polling are implemented in
../IEEE1394_bd; an uncertain pending request is retained, never freed on timeout.
Physical-console acceptance is still required.
November 25 follow-up: the response, write-request and read-request handlers read
each packet by its own length again, as the SDK does. Their nQuads argument is the
receive FIFO level the UBUF thread sampled before calling them, not the packet length;
the October checks dropped a packet that was still arriving and then parsed its
remaining quadlets as a new packet. test_ilink_manager_safety.py now feeds a level
smaller than the packet and requires the whole packet to be handled.
